# TravelTech — AI-помощник для планирования поездок

**Публичная версия исходного проекта ITAM Team для О! Хакатона 2026.**
Из одного запроса на естественном языке сервис формирует параметры поездки, соединяет данные из travel-источников и помогает сравнить варианты размещения, маршрутов и расходов.

## Что здесь

- `experimental/` — прототип backend/UI, маршрутизация запросов, интеграционные адаптеры.
- `prototype/` — ранний экспериментальный прототип и офлайн-проверки.
- `docs/ARCHITECTURE.md`, `docs/API_AND_STATE.md` — архитектура и контракты.
- `docs/CONFIGURATION.md` — настройка переменных окружения.
- `vendor/` — открытые зависимости с исходными уведомлениями о лицензиях.

## Начало работы

Установите зависимости из `requirements-team.txt` в отдельном виртуальном окружении и настройте **собственные** API-ключи как переменные окружения. Необходимые интеграции могут требовать доступа к сторонним сервисам. Для локального изучения доступны код и офлайн-режимы; отдельные demo-endpoint'ы используют фиксированные MOCK-данные.

Ключи, токены, сессии, командный транспорт, персональные данные, рабочие журналы и внутренние материалы QA намеренно **не включены** в эту публикацию. В публичном репозитории нет истории внутренних веток: это отдельный очищенный снимок кода.

**Моя роль:** руководство командой, требования и продуктовая архитектура, интеграция AI/API, проверка качества и демонстрация.

> Не используйте примерные или тестовые тарифы для реального бронирования без повторной проверки данных у поставщиков.
