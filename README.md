# TravelTech

**AI-помощник для планирования поездки — от свободного запроса до проверяемого предложения.**

Командный проект ITAM для **О! Хакатона 2026**. Пользователь описывает путешествие обычными словами; система разбирает город, даты, гостей и бюджет, уточняет недостающее, показывает редактируемое предложение и помогает сравнивать варианты отелей.

## Продукт за 30 секунд

| От запроса | К результату |
| --- | --- |
| **Естественный язык** | Выделение города, дат, гостей и бюджета; уточняющие вопросы |
| **Контроль пользователя** | Предпросмотр и ручная корректировка условий до подтверждения |
| **Внешние источники** | Read-only поиск вариантов через LiteAPI sandbox и изолированные адаптеры других сервисов |
| **Проверяемое состояние** | SQLite, версии поездки, привязка результатов к запросу, защита от повторных операций |
| **Работа без платного API** | Воспроизводимый офлайн-режим и локальные тестовые сценарии |

## Запустить самостоятельно

Для просмотра интерфейса и логики подтверждения поездки **не нужны API-ключи**:

```bash
python -X utf8 experimental/full_server.py --port 8000
```

Открыть `http://127.0.0.1:8000`.

Проверка backend в автономном режиме:

```bash
python -X utf8 experimental/full_server.py --port 8833 --smoke
```

**Проверено:** автономный smoke-тест запуска интерфейса и сервера завершился успешно; вызовы внешних API и платных моделей отсутствовали. Для чтения актуальных тестовых тарифов нужен собственный ключ LiteAPI sandbox — [настройка](docs/CONFIGURATION.md).
